Open source

The frame ships in public. The engine is the licence.

The Readiness Kit (harness, adapters, rubric, BOM emitter and a starter attack pack) is released under Apache-2.0 on GitHub and PyPI, so buyers can read what the Gate runs and integrators can build on it. v0.1.0 was tagged on 22 October 2026 (planned for 18 October 2026, four days late). The MCPSentry scanner follows in Q1 2027.

Start free

Three commands. A scorecard in about a second.

The Kit is the free start of every Gate conversation: run it on your own agent first, then decide whether you want the full attack pack, the report and the CI gate. Nothing you run here leaves your machine.

  1. 01
    pip install readiness-kit

    Python 3.10 or later, on Linux, macOS or Windows. No account, no key, no telemetry.

  2. 02
    rk demo

    Runs the whole pipeline on a bundled, deliberately weak support-ticket agent, offline, in about a second: held-out pass rate, attack findings, scanner results, BOM, cost per task and the scorecard.

  3. 03
    rk init

    Writes rk.yaml and the templates for your own agent; point them at an HTTP endpoint, a Python function, an OpenAI-compatible chat endpoint or a command, then run the same seven commands. The walkthrough takes ten minutes.

What rk demo prints is the demo agent's own result; it fails on purpose so the output is worth reading. The ten-minute walkthrough goes from the demo to your agent. Run the attack pack against a staging agent with outbound tools stubbed: the cases are real attacks and your agent may act on them.

Repository 01

Readiness Kit

The frame under the Agent Readiness Gate, in public: the harness that runs an evaluation set against an agent and scores it, the adapters for the open scanners, the eight-area rubric, the Agent BOM emitter and a starter attack pack. Buyers can read what the Gate runs and how it scores; integrators can build on it. The engine (the full attack pack, the domain packs, the seed sets, the report generator and the CI gate) ships in the licence.

What is in it

  • harness/Runs an evaluation set against an agent over HTTP, a Python function, an OpenAI-compatible endpoint, a command or a replay file; grades each case with ten deterministic graders; keeps a held-out split so the headline number is on cases the agent was not tuned on. The seed sets, and the seeding of a set from an agent's own traces, are part of the licensed Gate.
  • attack-pack/Twelve starter cases over OWASP ASI01–ASI10, one YAML file per class, each with a deterministic oracle and a remediation, in the format the full pack uses. Enough to run the harness end to end and to see what a finding looks like. The full pack and the domain packs are licensed.
  • rubric/The eight-area readiness scorecard: the areas, the weights, the bands and what each band means, with the Evidence Report's schema (not its generator).
  • bom/Emits a CycloneDX 1.6 Agent Bill of Materials (models, prompts, tools, MCP servers, skills, data sources) from an agent's manifest plus what it discovers on disk, and flags everything unversioned or unpinned.
  • cost/Cost per completed task from OpenTelemetry, OTLP or Langfuse traces, or from the Kit's own run: tokens, retries and tool calls, against a ceiling, projected to volume.
  • adapters/Runners for Cisco mcp-scanner, Snyk agent-scan, SPLX Agentic Radar and Promptfoo, so the Kit orchestrates the open scanners rather than re-implementing them; raw output kept, findings normalised.

How we do open source

Four commitments.

Frame open, engine licensed

The harness, adapters, rubric, BOM emitter and a starter attack pack are public. The full attack pack, the domain packs, the seed sets, the report generator and the CI gate are what a licence buys.

Honest version numbers

v0.1 means v0.1. No back-dated history, no purchased stars, no release announced before it is tagged.

Nothing moves behind a paywall

What ships in the open tier stays in the open tier. New licensed capability is added to the products; nothing is taken out of the Kit.

Security disclosures

Vulnerabilities in our tools go to security@rainkernel.com or the repository's private advisory; see security.txt. We credit reporters.

The Lab's log and advisories are on the Rainkernel Lab page. This website is itself open to inspection: it is a static site with a strict Content Security Policy, no cookies, no third-party scripts beyond the contact form's bot check, and a published security.txt. Details on Security and trust.
