Repository 01

Readiness Kit

The frame under the Agent Readiness Gate, in public: the harness that runs an evaluation set against an agent and scores it, the adapters for the open scanners, the eight-area rubric, the Agent BOM emitter and a starter attack pack. Buyers can read what the Gate runs and how it scores; integrators can build on it. The engine — the full attack pack, the domain packs, the seed sets, the report generator and the CI gate — ships in the licence.

What is in it

  • harness/Runs an evaluation set against an agent over HTTP or a local adapter, scores each run against expected outcomes, keeps a held-out split so the number cannot be gamed. The seed sets, and the seeding of a set from an agent's own traces, are part of the licensed Gate.
  • attack-pack/A starter set of agent-specific attack cases, one or more per OWASP ASI01–ASI10 entry, in the format the full pack uses — enough to run the harness end to end and to see what a finding looks like. The full pack and the domain packs are licensed.
  • rubric/The eight-area readiness scorecard: the areas, the weights, the bands and what each band means, with the Evidence Report's schema (not its generator).
  • bom/Emits a CycloneDX-shaped Agent Bill of Materials — models, prompts, tools, MCP servers, skills, data sources — from a running agent's configuration.
  • cost/Cost-per-task baseline: tokens, retries and tool calls per completed task from OpenTelemetry-style traces, projected to production volume.
  • adapters/Runners for snyk-agent-scan, Cisco mcp-scanner, Agentic Radar and Promptfoo, so the Kit orchestrates the open scanners rather than re-implementing them.

How we do open source

Four commitments.

Frame open, engine licensed

The harness, adapters, rubric, BOM emitter and a starter attack pack are public. The full attack pack, the domain packs, the seed sets, the report generator and the CI gate are what a licence buys.

Honest version numbers

v0.1 means v0.1. No back-dated history, no purchased stars, no release announced before it is tagged.

Nothing moves behind a paywall

What ships in the open tier stays in the open tier. New licensed capability is added to the products, never taken out of the Kit.

Security disclosures

Vulnerabilities in our tools go to security@rainkernel.com or the repository's private advisory; see security.txt. We credit reporters.

The Lab's log and advisories are on the Rainkernel Lab page. This website is itself open to inspection: it is a static site with a strict Content Security Policy, no cookies, no third-party scripts and a published security.txt. Details on Security and trust.
